# monitoring/

Hardware inventory and live metrics for the dashboard.

## Responsibilities

- Inventory: OS, CPU, RAM, GPU(s), VRAM
- Live utilization: CPU / RAM / GPU / VRAM, network quality, uptime
- NVIDIA, AMD and Intel support
- **AI service detection** (post-MVP): Ollama, Open WebUI, ComfyUI, Jupyter,
  Stable Diffusion UIs, vLLM — discovered carefully and securely, locally only
- Metrics are summarized for humans by default; raw detail is available in
  Advanced views and diagnostics

**Status:** design stage.

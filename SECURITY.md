# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| latest release | ✅ |
| older releases | ❌ — please update |

## Reporting a vulnerability

**Do not open a public issue for security vulnerabilities.**

Please report privately via GitHub's private vulnerability reporting:
<https://github.com/berkkarabacak/nodedesk/security/advisories/new>

Include:

- affected version(s) and platform
- steps to reproduce / proof of concept
- impact assessment

You can expect acknowledgment within 72 hours. We follow coordinated
disclosure: a fix and advisory are prepared before public details.

## Scope notes

- NodeDesk's own code, installer, update mechanism, agent, and its
  configuration of Sunshine/Moonlight are in scope.
- Vulnerabilities in unmodified upstream Sunshine/Moonlight code should also
  be reported to those projects; we will coordinate.
